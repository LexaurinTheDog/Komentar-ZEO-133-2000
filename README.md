# Komentář k zákonu č. 133/2000 Sb., o evidenci obyvatel a rodných číslech a o změně některých zákonů (zákon o evidenci obyvatel)

Otevřený komentář k zákonu o evidenci obyvatel — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; informační systém evidence obyvatel, poskytování údajů, trvalý pobyt, rodná čísla a jejich přidělování, změna a ověřování, přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2000-00133_2025-01-01`.
